# Empire Tycoon (TypeScript & JavaScript)

A Monopoly-inspired board game implementation built with TypeScript and JavaScript.

## Features

- 🎲 Monopoly-style gameplay
- 💰 Property buying and rent system
- 🎯 Turn-based game mechanics
- 🧩 Built with TypeScript and JavaScript
- 🚀 Easy to modify and extend

## Getting Started

### Clone the repository

```bash
git clone https://github.com/AlterioFarto/empire-tycoon.git
cd empire-tycoon
```

### Install dependencies

```bash
pnpm install
```

### Run the project (Client and Server)

```bash
npm run dev
```

## Technologies

- TypeScript
- JavaScript
- Node.js
- React.js
